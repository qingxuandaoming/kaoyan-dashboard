说明：
- 选择题/判断题归为一个文件，填空/简答归为一个文件，与仓库既有约定一致
  （判断题在 Anki 中化为 A.正确 / B.错误）。
- 选择题在墨墨中使用**固定选项顺序**（`fixed`），解析里提到的选项位置才对得上。
- 题库中没有图片；含 LaTeX 的题目（`$...$`）已分别转为
  Anki 的 `\(...\)` 和墨墨的 `[E##...]` 公式语法。

## 三、导入墨墨记忆卡（Markji）步骤

墨墨记忆卡网页版没有 Anki/.apkg 导入入口，官方支持的方式是
**「批量制卡 → 从文本导入」**，卡间用独占一行的 `===` 分隔（文件已处理好）。

1. 电脑浏览器打开 <https://www.markji.com> 并登录。
2. 「牌库」中新建 4 个牌组，建议命名：
   `考研408`、`考研数学一`、`考研英语一`、`考研政治`。
3. 进入某个牌组 → 点击「批量制卡」→ 选择「从文本导入」。
4. 用记事本打开 `Markji/` 下对应科目的 `.txt`，**全选复制**内容，粘贴到输入框。
5. 先确认右下角识别出的卡片数量（408=156、数学一=156、英语一=99、政治=164），
   建议先翻看前几张预览，确认选择题、挖空、公式显示正常，再点「导入」。
6. 其余三个科目重复第 3–5 步。手机 App 登录同一账号会自动同步。

注意：大批量导入前可先粘贴 1–2 张卡测试排版，确认无误再整段导入。

## 四、导入 Anki 步骤（如需在 Anki 中使用）

1. 打开 Anki 桌面端，建议先建 4 个空牌组。
2.「文件 → 导入」，选择 `Anki/<科目>/<科目>_Anki_选择.csv`：
   - 导入对话框中类型选「基础」，字段分隔符应为 Tab，勾选「允许 HTML」；
   - 目标牌组选对应科目，标签列按文件头自动识别，点「导入」。
3. 再导入同目录的 `<科目>_Anki_问答.csv`。
4. 含公式的卡片需 Anki 内置 MathJax（桌面端默认支持）。
